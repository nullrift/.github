# NullRift

A one-person dev organization because "personal account" felt too casual and "LLC" felt too ambitious.


## What is this?

NullRift is the cover name for my personal development projects. Right now that's mostly one project: an end-to-end encrypted messenger, but the org name sounded cool enough to commit to long-term.

The name comes from two ideas I keep coming back to:

- **Null** — zero ads, zero bloat, zero unnecessary complexity
- **Rift** — breaking from whatever the default assumption was

## How I Work

- TypeScript pretty much everywhere. Runtime type errors have burned me enough already.
- Tailwind because writing CSS by hand in 2026 is a personal choice I've stopped making.
- Tauri > Electron. I don't need Chromium with my notes app. (screw 100MB installers that could be 10MB)

## Security Issues

If you find something broken please tell me before the internet does.

Open an issue or reach out directly. No bug bounty, but you'll get genuine appreciation and your name in a comment somewhere meaningful.

## Contributing

This is mostly a personal sandbox, but if something here is useful to you and you want to improve it... sure! Open an issue first so we're not working against each other.

```bash
git clone https://github.com/nullrift/<repo>
cd <repo>
pnpm install
pnpm run dev
```
<sub>Yes I use pnpm, but take whatever you are used to.</sub>
